深圳公交全网程序快速使用

1. 安装
   python -m venv .venv
   macOS/Linux: source .venv/bin/activate
   Windows: .venv\Scripts\activate
   pip install -r requirements.txt

2. 配置
   复制 .env.example 为 .env
   填入 AMAP_JS_KEY 和 AMAP_SECURITY_CODE

3. 启动
   python app.py

4. 打开批量采集
   http://127.0.0.1:8000/collector
   先采集 20 条测试，再逐批继续。程序可暂停、续跑，已完成数据保存在 data/bus.db。

5. 人工复核
   在采集页面右侧为 review/failed 项指定正确的上行或下行候选。

6. 构建全网
   点击“构建全网”，或运行：
   python build_network.py

7. 查看
   http://127.0.0.1:8000/

8. 更新官方 Excel
   python sync_official.py
   然后只采集新增或发生变化的线路，再重新构建。

完整说明见 README.md。
