本版本修复启动错误：
TypeError: Unable to evaluate type annotation 'str | None'

修复范围：
1. app.py 中 Pydantic 请求模型的 str | None、list[...]、dict[...]。
2. app.py、db.py、build_network.py、sync_official.py 中全部新式类型注解。
3. 改为 Optional、List、Dict、Tuple、Set 等兼容写法。
4. 不需要安装 eval_type_backport。

运行：
1. 进入项目目录。
2. 激活原虚拟环境，或重新创建 .venv。
3. pip install -r requirements.txt
4. python app.py
5. 打开 http://127.0.0.1:8000/collector

建议 Python 3.9 或更高版本。
